# 🖥️ Computer Quiz Game (Python)

A simple, interactive computer quiz game built with Python. It tests the player's basic computer knowledge through questions about common hardware components.

## 📌 Features

* Interactive welcome message
* Option to start or exit the quiz
* Four computer-related questions
* Case-insensitive answer checking
* Score tracking for correct answers
* Final score and percentage calculation

## 🛠️ Technologies Used

* **Python 3**
* `input()` for user interaction
* `if-else` statements for answer checking
* Variables and arithmetic operations for score calculation

## ❓ Quiz Questions

1. What does CPU stand for?
2. What does GPU stand for?
3. What does RAM stand for?
4. What does PSU stand for?

## 🚀 How to Run

1. Install Python 3 on your computer.
2. Clone this repository or download the project files.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python quiz.py
   ```

   Replace `quiz.py` with your Python file's actual name if it is different.
